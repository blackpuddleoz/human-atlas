# Supplemental anatomy model

Source: https://github.com/Charleeh/ecorche/blob/main/model/ecorche.glb
License: Creative Commons Attribution-ShareAlike 4.0 International
https://creativecommons.org/licenses/by-sa/4.0/

This subset retains 14 supplemental muscles and five registration bones from
Charleeh/ecorche. Upstream mesh metadata credits BodyParts3D and Z-Anatomy;
quadratus lumborum meshes are credited to Z-Anatomy. Original mesh names and
source metadata are retained in the glTF nodes.

Changes: selected meshes extracted, unused colors and materials removed, binary
buffers embedded in a self-contained glTF. Mesh positions, normals, topology and
node transforms are preserved. This adapted model is distributed under CC BY-SA 4.0.
